Close the game first

Quit Sons of the Forest before you edit or replace a save. The game rewrites its save files while running and can overwrite your changes or corrupt the save.

Unequip items in game before you save and quit. Equipped items are shown here but can't be edited.

This is a fan tool with no connection to Endnight Games. Your save never leaves your computer.

Download the new save

You'll get a new SaveData.zip with your changes.

Keep your original file as a backup. Copy it somewhere safe before you replace it, in case the modified save doesn't load.

Then put the new file in your save folder, replacing the old one, and start the game.
